# Hospital Operations, Cost & Patient Flow Intelligence

## Project Overview

This project investigates hospital operations, encounter patterns, healthcare costs, payer coverage and procedure utilisation using historical healthcare datasets provided by AnalystLab Africa.

The objective is to develop an interactive Healthcare Operations & Financial Intelligence Dashboard that supports evidence-based operational decision-making.

## Business Objectives

- Analyse hospital encounter volumes and patterns.
- Examine encounter classes and patient flow.
- Investigate healthcare costs and payer coverage.
- Evaluate procedure frequency and utilisation.
- Develop actionable, evidence-based business recommendations.

## Tools & Technologies

- Python and pandas
- PostgreSQL and SQL
- Microsoft Power BI
- Power Query and DAX
- Excel

## Project Structure

- `data/` – Raw and processed datasets
- `notebooks/` – Exploratory analysis and investigations
- `scripts/` – Python scripts
- `sql/` – SQL queries and reference scripts
- `documentation/` – Project and analytical documentation
- `reports/` – Final reports
- `powerbi/` – Dashboard files and screenshots
